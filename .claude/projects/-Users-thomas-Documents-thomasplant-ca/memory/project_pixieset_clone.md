Thomas is building a Pixieset clone — a photo gallery and client delivery platform for photographers.

**Why:** Personal project to learn full-stack infra (Docker, S3-compatible storage, AWS deployment, CI/CD) while building something useful.

**How to apply:** Prioritize teaching infra concepts when making suggestions. Use MinIO locally (S3-compatible) so the switch to AWS S3 is seamless. Keep the architecture production-realistic even in local dev. When there are multiple ways to do something, prefer the approach that teaches more about infrastructure.
